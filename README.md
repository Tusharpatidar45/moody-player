# Moody Player

A mood-based music recommendation app built using React, Node.js, MongoDB, ImageKit and Face-API.js.

## Features

* Real-time Mood Detection
* Facial Expression Recognition
* Mood-Based Song Recommendations
* Audio Upload with ImageKit
* MongoDB Integration

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* ImageKit
* Face-API.js
